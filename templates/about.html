About Smart Farmer Assistance & Crop Management System

A complete, modern full-stack web application built using Python, Django, Django REST Framework, MySQL, Pandas, NumPy, and Bootstrap 5.

Our Objective

The main purpose of the platform is to empower farmers by providing a unified digital portal for managing crop cycles, checking live local weather forecasts, conducting soil analysis, receiving data-driven crop recommendations, diagnosing crop diseases, and keeping track of market commodity prices.

Key Technical Highlights

Django MVC Architecture

Clean app modularization across Accounts, Crops, Weather, Soil, Recommendations, Diseases, and Market.

Open-Meteo Weather Integration

Free external REST API integration without API key requirements or paid dependencies.

Pandas & NumPy Data Processing

Data-driven scoring algorithms for soil analysis and crop recommendations based on soil NPK, pH, and climate.

Secure Authentication & Role Access

Role-based access control distinguishing Farmer profiles from System Administrators.

Disclaimer: Recommendations and disease treatment data provided in this application are for informational and demonstration purposes only. Farmers should consult qualified local agricultural extension officers before making critical farming decisions.
